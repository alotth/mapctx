# MapCtx 0.3.1

CLI/web consolidation after store/history and Acceptance delivery.

- Standalone browser assets/tests moved into sync-engine; no dependency on VS Code package.
- VS Code/OpenCode UI integrations and exclusive build/install/release tools retired from main, preserved in `legacy/integrations-pre-0.3.0` at c6c3efa.
- Root build/test commands now cover maintained packages. CLI engine requirement corrected to Node 22.13+ for built-in SQLite.
- Includes recent canonical Acceptance, atomic claim+dispatch, provenance-aware history correction/recovery and authored prose preservation. Existing migrations/events/receipts are retained.
- Operational validate reads DB/config; mirrors published at explicit final checkpoints. Existing projects need explicit observed-checkbox Acceptance adoption, not automatic approvals.
- `mapcs` compatibility, Traycer adapter, skills and OpenCode session-history ingestion remain.

See [upgrade/release runbook](engine.md). Previously installed editor integrations are not removed from their marketplaces.

0.3.0 was an unpublished release candidate: clean Linux CI found a missing direct @types/node development dependency in the Traycer adapter. 0.3.1 declares it explicitly; sync-v0.3.0 remains unchanged as historical evidence.
