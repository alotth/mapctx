# Correction Template

Use this template when a correction needs explicit structure inside a task detail file or operator report.

## Trigger

- What changed?
- When was it discovered?
- What assumption or condition no longer holds?

## Impact

- Acceptance affected:
- Dependencies affected:
- Verification affected:
- Scope increase, decrease, or redirect:

## Landing Zone

- Update task detail only
- Update task detail + `TASKS.md`
- Update task detail + `docs/ROADMAP.md`
- Update task detail + ADR/methodology docs

## Decision Trail

- `Open Decisions for Execution` for unresolved questions
- `Decisions Taken` for dated resolutions
- `Implementation Notes` for where the correction landed in code or docs
