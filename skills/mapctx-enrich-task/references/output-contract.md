# Output Contract

When this skill finishes, the enriched task detail file should:

- keep product intent ahead of technical guidance
- improve operator confidence without creating a second source of truth
- avoid speculative answers to open questions
- point to concrete files, docs, ADRs, or commands only when they are relevant

Minimum useful output:

- clearer `Product Context`
- clearer `Expected Outcome`
- sharper `Acceptance`
- explicit `Constraints` or `Open Decisions for Execution` when ambiguity remains

Optional output for heavier tasks:

- dependency context from prerequisite tasks
- verification hints or test commands
- implementation landing spots under `Implementation Notes`
- recommendation to create `tasks/<ID>.plan.md`
