      ## Product Context
      MapCtx already has a strong data contract, but needs richer execution workflows to improve planning quality and delivery speed.
      The workflow layer should reduce repeated operator work without creating a second planning system or making subagents the default for ordinary tasks.

      ## User Story
      As an operator, I want advanced workflow skills on top of the current contract so I can run projects faster without losing consistency.

      ## Acceptance
      - [ ] New workflow skills follow current task contract.
      - [ ] Workflows improve planning, next-action guidance, and scope correction.
      - [ ] New flows stay low-token by default and escalate to subagents only for complex work.
      - [ ] Execution waves are supported in operational loops.

      ## Steps
      - [ ] add task enrichment workflow.
      - [ ] add sprint-status and next-action workflows.
      - [ ] add scope-correction and wave execution workflows without introducing a competing source of truth.
