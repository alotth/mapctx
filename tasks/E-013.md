  - summary: mapctx push reads store projections and publishes GitHub issues/status; closes the last Markdown-reader path (R13) before mapcs removal
  - description: |
      ## Product Context

      ADR 0003 defines GitHub as an explicit projection of the store — never a source. Today the only
      GitHub publishing path is the legacy `mapcs` push, which still reads Markdown and is blocked by
      guard R13 as a second writer. With store authority in place (0.1.1, dogfood on projectId
      9176b907), the push must be re-based onto store projections.

      ## Expected Outcome

      - `mapctx push` publishes issues/status on GitHub by reading projections from the SQLite store
        (tasks, status, externalId), not from TASKS.md.
      - The flow is fail-closed: push refuses to run when the board snapshot has drift, so GitHub can
        never diverge silently from the store.
      - This epic is the closure of the R13 finding's durable form and retires the last legacy-reader
        path before `mapcs` removal.
