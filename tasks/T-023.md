  - description: |
      ## Product Context
      Independent evaluation increases trust in completion markers and reduces false positives, but it also adds execution cost.
      MapCtx should spend that extra rigor where it materially improves confidence instead of making every standard task heavier.

      ## User Story
      As a maintainer, I want evaluation to run with fresh context so done/review transitions reflect real quality.

      ## Acceptance
      - [ ] Isolated evaluator run is default for `strict` or otherwise high-risk work, not blanket `standard` work.
      - [ ] `standard` work can stay single-agent unless the operator or risk signals justify isolation.
      - [ ] Handoff bundle is passed without generator-only context.
      - [ ] Transition outcomes remain deterministic.

      ## Steps
      - [ ] add routing gate based on `specMode`, workload, and risk.
      - [ ] integrate evaluator stage into strict/high-risk execution flow.
      - [ ] enforce handoff contract usage.
      - [ ] verify compatibility with current completion markers.
