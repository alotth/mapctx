  - summary: Define vNext entities, state ownership, workflow gates, cost/time measures, and versioned sync-safe contracts.
  - description: |
      ## Product Context
      MapCtx needs stable boundaries before replacing Markdown state or connecting executors.
      Every downstream task (store, dispatch, forecast, adapter) depends on identity,
      versioning, and event-ordering rules that do not exist yet.

      ## Expected Outcome
      Implementers share one executable model for tasks, claims, artifacts, dispatches,
      events, usage, cost, and estimates — with rules that survive a later multi-host store.

      ## Acceptance
      - [x] Every entity has an executable schema plus a versioned golden fixture; contract tests fail on drift.
      - [x] `schemaVersion` is present in `DispatchEnvelope`, `RunEvent`, and `RunReceipt`, with a documented compatibility rule and a test that rejects an incompatible version.
      - [x] Identity scheme documented with a worked example linking MapCtx task, Traycer epic/artifact, and GitHub issue; `ExternalRef` is a first-class entity.
      - [x] `planningState` and `executionState` are separate state machines; illegal transitions are enumerated and tested.
      - [x] Event log entries are identified by `(nodeId, sequence)`; no schema, query, or invariant depends on a global autoincrement, and every projection is rebuildable from the log alone, so two hosts can merge by shipping events.
      - [x] `UsageEvent` carries `source` (harness-transcript | provider-api | manual | absent) and `coverage`.
      - [x] `CostEvent` carries `billingType`, `costStatus`, and the three measures `cashCents`, `shadowMicros`, and `allocatedMicros`; `PlanPeriod` exists with `status: open|closed`.
      - [x] Duration measures are defined as data: `sessionWallClock`, `activeTime` with configurable idle threshold, `taskDuration` as union of session intervals, and `leadTime`.
      - [x] `EstimateSnapshot` is immutable and records method, confidence, estimator version, idle threshold, and cost coverage.
      - [x] Host workflow gates are modelled as data, including the `skipped` case with a reason.
      - [x] Migration rules assign every field currently in `TASKS.md` and `tasks/*.md` one destination: persist, derive, or drop.

      ## Decisions Taken
      - [2026-08-15] MapCtx plans; harnesses execute; Git stores promoted decisions.
      - [2026-08-15] Cost is three measures, never one. Forecast uses `shadowMicros`; allocation is provisional until the period closes.
      - [2026-08-15] Event identity is `(nodeId, sequence)` from day one so multi-host sharing is event shipping, not a store rewrite. No engine mandate; default install is plain local SQLite with no service dependency.
      - [2026-08-15] Duration forecasting uses `activeTime`; Gantt shows wall clock and lead time.
      - [2026-08-15] Schema is Zod-first; JSON Schema is generated/versioned from it. Adapters get a neutral contract without two sources.
      - [2026-08-15] Shadow price table is a vendored, versioned file. Runtime lookup would mutate historical `shadowMicros`. Each `CostEvent` records `priceTableVersion` and the applied rate.
      - [2026-08-15] Under `plansAuthority: store`, the entire structured block of `tasks/<ID>.md` is generated; only `description:` prose stays Git-authored.
