      ## Product Context
      Three surfaces were built before ADR 0003 drew the boundary between MapCtx planning and harness execution. They now
      contradict the thesis in code while the docs claim the opposite, and an unowned kill list stays unowned. Blanket
      deletion is wrong: their consumers differ, and one of them hosts the only UI the Gantt dogfood can land in.

      ## Expected Outcome
      Each surface carries one written disposition that a reader can verify from the repository, and the surface removed
      is actually gone rather than deprecated in a comment.

      ## Acceptance

            VS Code thread panel consuming `readThreadContext` in `unifiedWebviewPanel.ts` is removed.
            workspace-server.ts internally uses thread.ts and is frozen; thread.ts stays as internal file.
            Extension builds successfully.
      - [x] ADR 0002 is marked `Superseded by ADR 0003` (already done).
            `docs/thread-substrate.md` has superseded header in first paragraph (already done).
      - [x] `packages/sync-engine/src/workspace-server.ts` stays, with header comment (FROZEN...) and README line stating
            it is frozen: no new features, fixes limited to keeping build green, revisited at external-adoption gate.

      - [x] `packages/opencode-plugin` is marked deprecated in `package.json` with text "Removed in E-012 unless a user appears"
