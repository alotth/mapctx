  - description: |
      ## Product Context
      Fixtures and disposable worktrees proved store mechanics, but this repository has never made the irreversible
      authority transition from Markdown to the external store. Installing globally before that would distribute a
      migration contract that has not survived its own real project.

      T-062 must first make commands reliable from agent worktrees and subdirectories. T-064 must first make
      `activeTime` measured when RunEvents exist. T-055 provides the honest pre-cutover Gantt baseline. Only then is
      a real `mapctx import --commit` meaningful evidence rather than a demo.

      ## Expected Outcome
      This repository switches once from `plansAuthority: markdown` to `plansAuthority: store`, preserves a committed
      Markdown checkpoint, and proves that CLI queries, workspace UI, export, and recovery agree after cutover.

      ## Acceptance
      - [ ] `mapctx import --dry-run --json` reports the exact project, board path, task count, and proposed authority
            change with no unexplained validation errors.
      - [ ] A git checkpoint containing the last Markdown-authoritative board is committed before cutover.
      - [ ] `mapctx import --commit --json` succeeds on this repository and flips `plansAuthority` in the same commit
            as the generated snapshot; no date-based or dual-master transition exists.
      - [ ] From both repository root and a nested subdirectory, `validate`, `plan`, `task context`, and `gantt` return
            the same project and task identities after cutover.
      - [ ] `TASKS.md`/structured detail fields are treated as generated read-only output; deliberate drift fails
            closed and names the affected task.
      - [ ] A wave-end export reproduces the canonical Markdown snapshot without semantic drift.
      - [ ] Recovery is rehearsed against a disposable copy of the project store: checkpoint restores task state and
            the documented loss boundary for pre-checkpoint events/claims/usage is confirmed.
      - [ ] Gantt still renders, now in `store` mode, and remains honest if no real receipts exist yet.

      ## Non-Goals
      - Global installation or publication.
      - Running the complete two-wave Traycer slice; T-056 owns that evidence.
      - Remote/multi-machine sync.

      ## Decisions Taken
      - [2026-08-26] Cutover is a separate gate, not an implicit first step of T-056. Migration/recovery evidence must
        exist before the larger dogfood slice can attribute failures to planning, execution, or telemetry.
      - [2026-08-26] Global installation remains blocked through T-057.

      ## Open Decisions for Execution
      - [resolved 2026-08-26] The recovery checkpoint is the commit created immediately before cutover, containing the
        last Markdown-authoritative board (76 tasks, 0 errors). Recorded by SHA in the T-066 thread and summary.
      - [resolved 2026-08-26] The disposable recovery copy lives in a temporary drill directory outside the repository
        and outside `~/.mapctx/projects/`; the drill never mutates the real project store.

      ## Steps

      - [ ] Commit the final Markdown-authoritative checkpoint.
