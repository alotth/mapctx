  - description: |
      ## Problem
      The Workspace V2 filter panel TAG field only does substring matching inside task tags. Typing an id/title fragment (e.g. "76" to find T-076) returns "No tasks match the selected filters" with no explanation — the filter is bad for searching. User expectation: LIKE-style partial matching.

      ## Decisions taken
      - The TAG field becomes a broad LIKE filter: each comma-separated token must be a case-insensitive substring of the task's id, title, or tags (AND across tokens; OR across the three fields per token).
      - Status/type/priority/workload/thread filters stay exact-select; the main search box is unchanged.
      - Field label/placeholder updated so the broader scope is discoverable (no dead end).
      - Pure workspaceV2.js/html change, no data or panel TypeScript changes.
