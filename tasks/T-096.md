  - summary: Ingest harness usage by dispatch and derive class-priced shadow cost
  - description: |
      ## Product Context

      Cost per task/epic is dead today: receipts arrive with `usageEvents: []`
      because Traycer's A2A protocol exposes only per-profile rate-limit gauges.
      The data can be on the harness host — Claude Code JSONL (`~/.claude/projects/...`,
      per-message `usage` incl. cache classes), OpenCode message JSON
      (`tokens` + native `cost`), Codex session JSONL (`token_count`). The
      cache-token pricing policy and the source hierarchy are now decided in
      ADR 0003 ("Usage ingestion from harness session stores", 2026-09-30).

      ## Expected Outcome

      - [ ] Importer module that reads a harness session (claude JSONL, opencode
        message JSON, codex sessions) and aggregates per-model token classes
        into `UsageEvent`s with `source: "harness-transcript"` and honest
        `coverage` (partial when the time window clips the session).
      - [ ] Session→dispatch mapping supplied by importer input (sessionId +
        provider + model + dispatch attempt), checked per record against the
        receipt time window;
        shared sessions are not counted in full for multiple dispatches, and
        unmatched records lower coverage instead of fabricating usage.
        Deduplicate repeated messages and derive deltas from cumulative
        counters. Mark remote or inaccessible session stores uncovered.
      - [ ] Append usage in its own replayable store event, with stable
        idempotency identity, before or after a receipt is accepted. Preserve
        receipt-embedded v1 usage and skip overlapping backfill.
      - [ ] `UsageEvent` schema v2: `cacheTokens` split into
        `cacheReadTokens`/`cacheWriteTokens`/`cacheUnknownTokens` with v1→v2
        mapping (v1 → unknown) across protocol, store projections, and
        fixtures. Classes are disjoint; `inputTokens` excludes cached input.
        Preserve historical v1 cost events without repricing.
      - [ ] `costEventFromUsage` priced per token class from a price-table v2
        that covers known exact provider/model IDs (incl. executed
        `zai/glm-*` models); unknown cache or missing model price is visibly
        `unpriced`. Harness-calculated cost remains a labeled estimate.
      - [ ] Wiring so imported usage derives one persisted shadow cost per
        usage event. Expose shadow totals and coverage per task and epic.
        Reported API spend and plan allocation follow in T-097/T-098.
      - [ ] Tests: aggregation fixtures per harness format, v1 unknown-cache
        migration, class-rate pricing, repeated import, shared-session
        attribution, coverage labeling, and usage→shadow rollup.
