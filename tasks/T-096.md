  - summary: Ingest usage from harness session stores into receipts
  - description: |
      ## Product Context

      Cost per task/epic is dead today: receipts arrive with `usageEvents: []`
      because Traycer's A2A protocol exposes only per-profile rate-limit gauges.
      The data itself is on disk — Claude Code JSONL (`~/.claude/projects/...`,
      per-message `usage` incl. cache classes), OpenCode message JSON
      (`tokens` + native `cost`), Codex session JSONL (`token_count`). The
      cache-token pricing policy and the source hierarchy are now decided in
      ADR 0003 ("Usage ingestion from harness session stores", 2026-09-30).

      ## Expected Outcome

      - [ ] Importer module that reads a harness session (claude JSONL, opencode
        message JSON, codex sessions) and aggregates per-model token classes
        into `UsageEvent`s with `source: "harness-transcript"` and honest
        `coverage` (partial when the time window clips the session).
      - [ ] Session→dispatch mapping supplied by the receipt filer (sessionId +
        provider + model), cross-checked against the receipt time window;
        unmatched sessions lower coverage and never fabricate events.
      - [ ] `UsageEvent` schema v2: `cacheTokens` split into
        `cacheReadTokens`/`cacheWriteTokens` with documented v1→v2 mapping
        (v1 → cacheWrite, conservative) across protocol, store projections,
        and fixtures.
      - [ ] `costEventFromUsage` priced per token class from a price-table v2
        that covers every provider/model this store executes (incl.
        `zai/glm-*`); harness-reported cost (opencode `cost`, claude
        `total_cost_usd`) lands as `cashCents: reported` alongside shadow.
      - [ ] Wiring so the chain runs end to end: receipt acceptance (or
        `mapctx cost derive`) converts ingested usage into persisted cost
        events; `mapctx budget status <epic>` then shows real consumption.
      - [ ] Tests: aggregation fixtures per harness format, v1→v2 migration,
        class-rate pricing, coverage labeling, end-to-end receipt→budget rollup.
