  - summary: Attribute API and OpenRouter charges to dispatches at sub-cent precision without double counting credits.
  - description: |
      ## Product Context

      API and OpenRouter runs need task and epic costs that reflect actual debits when available. A model list price is useful for comparison but does not prove what was charged. Per-generation charges can be smaller than one cent.

      ## Expected Outcome

      - [ ] Associate a billing record with a dispatch attempt using a stable generation or request ID; never infer per-task spend from account-wide totals.
      - [ ] Import OpenRouter generation `total_cost` as reported credit debit. Record upstream BYOK charges only from the provider billing source; do not count top-ups and debits twice.
      - [ ] Optionally fetch current OpenRouter model pricing for shadow cost and snapshot the exact applied rates/version; catalog changes do not reprice past runs.
      - [ ] Support reported API spend at USD-micro precision in the versioned CostEvent contract and budget rollup. Convert historical `cashCents` exactly without repricing.
      - [ ] Keep reported spend, list-price shadow, and billing provenance distinct; missing billing records remain estimated or unattributed.
      - [ ] Test sub-cent charges, duplicate imports, BYOK, credit accounting, and task/epic rollups.
