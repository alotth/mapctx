  - summary: Extract per-owner intervals from Claude Code transcripts into receipt evidence so activeTime is measured and human/parked time is reported separately.
  - description: |
      ## Product Context

      Receipts carry only `startedAt`/`endedAt`, so `activeTime` is always `substituted` (wall clock) and human wait time is not measured anywhere. Session transcripts already record who spoke and when, which lets every interval be attributed to whoever holds the ball: the agent working, or the human (review, decision, or parked on other focus). This separates agent active time from human time with the task, and makes "agent spent 18 min, task sat 3h with the human" a measurable, postable metric.

      Convention (see T-099): `estimatedEffort` = agent active time. Human time is reported separately and never enters the forecast.

      ## Model

      - Owner per interval: `agent` = human message -> end of assistant turn (inter-event gaps under idle threshold); `human` = end of assistant turn -> next human message; tool_result lines are not human messages.
      - Automatic human-interval class, thresholds configurable and recorded in estimate provenance: short (<=15m) `review`, mid (15m-2h) `human`, long (>2h or overnight) `parked`; raised parked confidence when the user was active in another session/task during the interval (cross-check via claims/sessions).
      - Optional `waitReason` on the task (`review|decision|parked|blocked-external`), never required.
      - Receipt `evidence` gains `intervals: [{start, end, owner, kind}]`: timestamps and owners only, never transcript content.
